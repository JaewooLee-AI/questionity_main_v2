## 🚀 시작하기

### 회원가입 프로세스

#### 1단계: 회원가입 페이지 방문
- 웹사이트 상단의 "시작하기" 버튼 클릭
- 또는 메인 페이지의 CTA 버튼 클릭

#### 2단계: 기본 정보 입력
```markdown
- 이메일 주소
- 비밀번호 (8자 이상)
- 이름 (닉네임 또는 실명 사용 권장)
```

#### 3단계: 가입 완료
- 가입 즉시 로그인 처리
- 개인 프로필 설정 페이지로 이동
- 관심 카테고리 선택 가능

### 로그인 방법
- **이메일**: 가입 시 입력한 이메일
- **비밀번호**: 설정한 비밀번호
- **소셜 로그인**: Google 계정 연동 (선택사)

## 👥 회원가입

### 가입 유형

#### 일반 회원
- 도서 큐레이션 탐색 가능
- 무료 도서 추천 받기
- 커뮤니티 소식 이용

#### 1st Season 멤버
- 독서 모임 참여 가능
- 전용 혜택 혜택 제공
- 오프라인 라운지 우선 입장

### 가입 혜택
- **무료 회원**:
  - 300선 도서 큐레이션 접근
  - 월사이트 이용 권한
  - 뉴스레터 수신 (선택)

- **1st Season 멤버**:
  - 월 3회 오프라인 독서 모임 참여
  - 전용 커뮤니티 공간 이용
  - 도서 구매 10% 할인
  - 월간 1:1 문답 코칭

### 가입 절차
1. **온라인 가입**: 웹사이트에서 회원가입 완료
2. **문자 메시지**: 가입 축하 메시지 발송
3. **프로필 완성**: 관심 분야 및 독서 취향 설정
4. **멤버십 활성화**: 1st Season 모집 기간 중 혜택 제공

## 🔍 독서 모임 탐색

### 카테고리별 도서 탐색

#### 사용 가능한 카테고리
```
💼 경제경영     - 비즈니스, 투자, 리더십
🌱 자기계발     - 습관 형성, 성장 심리학
📚 인문학        - 철학, 사상, 역사
💻 IT/컴퓨터   - AI, 프로그래밍, 기술 트렌드
✍️ 소설/시/희곡   - 문학, 에세이, 희곡
🌍 사회과학      - 사회 현상, 정치, 심리학
```

### 도서 검색 방법

#### 1. 카테고리 필터
- 원하는 카테고리 버튼 클릭
- 카테고리별 도서 목록 자동 표시

#### 2. 키워드 검색
- 검색창에 도서명, 저자명 입력
- 실시간 검색 결과 표시
- 태그 기반 검색 지원

#### 3. 🎲 새로고침 기능
- 버튼 클릭 시 매번 다른 순서로 도서 추천
- 무한 리프레시 모드
- 새로운 발견 가능

### 도서 정보 확인
- **도서명**: 원서명과 번역명
- **저자**: 작가명 (국내/해외)
- **출판사**: 출판사 정보
- **카테고리**: 분류 카테고리
- **태그**: 키워드 태그
- **알라딘 링크**: 알라딘 상세 페이지 바로가기

## 📝 모임 신청하기

### 신청 가능한 모임 상태

#### 🔥 모집중인 모임
- 신청 가능한 모임 (현재 8개 모임 모집중)
- 정원 미달 시 신청 마감
- 선착순 마감

#### ⚡ 진행중인 모임
- 현재 활발히 진행 중인 모임
- 다음 시즌 모집 기간 확인 가능
- 현재 멤버들의 활동 확인 가능

#### ✅ 종료된 모임
- 과거 진행했던 모임
- 후기 내역 확인 가능
- 재개설 기간 확인 가능

### 신청 절차

#### 1단계: 희망 도서 선택
- 관심 있는 도서를 1권 이상 선택
- 여러 카테고리에서 선택 가능
- 최대 10권까지 선택 가능

#### 2단계: 신청서 작성
- **기본 정보**:
  - 신청자 성명
  - 연락처 (전화번호)
  - 참여 동기
  
- **추가 정보**:
  - 해당 도서를 읽어본 경험
  - 기대하는 토론 주제
  - 다른 멤버들과의 교류 희망

#### 3단계: 결제
- **결제 금액**: 모임별 상이 (예: 89,000원)
- **결제 수단**: 신용카드, 카카오페이, 토스
- **할인 혜택**: 1st Season 멤버 10% 할인

#### 4단계: 신청 완료
- 자동 확인 문자 발송
- 담당 클럽 매니저 배정
- 모임 일정 안내 공지

## 💳 결제 방법

### 결제 수단

#### 1. 신용카드
- Visa, Mastercard, AMEX
- 3개월 할부 지원
- SSL 보안 결제 시스템

#### 2. 간편결제
- **카카오페이**: 카카오톡 연동
- **토스**: 토스페이 간편결제
- **무통장입금**: 가상 계좌이체

### 결제 프로세스

#### 1단계: 결제 수단 선택
- 원하는 결제 수단 선택
- 결제 수단별 혜택 안내 확인

#### 2단계: 결제 정보 입력
```markdown
- 신용카드: 카드번호, 유효기간, CVC
- 간편결제: 간편결제 앱 링크로 이동
- 무통장입금: 은행 계좌이체 입금
```

#### 3단계: 결제 완료
- 결제 성공 시 자동 확인
- 영수증 발송 (이메일)
- 모임 참여 확정

### 환불 및 취소
- **모임 시작 7일 전까지**: 전액 환불 가능
- **모임 시작 3일 전까지**: 50% 환불
- **그 이후**: 환불 불가, 취소 불가
- 환불 요청은 담당 매니저에게 문의

## 📚 모임 참여 방법

### 모임 일정

#### 기본 일정 (4주 프로그램)
```
1주차: 책 소개 및 기대 토론
  - 독서 방법 공유
  - 기대 토론 및 질문 생성
  
2주차: 핵심 주제 심층 토론
  - 중요 챕터 분석
  - 현실 적용 방안 논의
  
3주차: 실천 미션 공유
  - 주간 실천 과정 공유
  - 피드백 및 서로 리뷰
  
4주차: 마무리 및 다음 도서 선정
  - 전체 정리 및 인사이트 공유
  - 다음 독서 모임 논의
```

#### 모임 시간 및 장소
- **시간**: 매주 정해진 시간 (예: 화요일 19:30)
- **장소**: 혜화 독서 아지트 (종로구 창경궁로 270)
- **진행 방식**: 오프라인 + 온라인 하이브리드
- **참여 인원**: 8-12명 (소규 모임)

### 모임 참여 혜택

#### 1st Season 멤버
- **비용**: 무료 (8회 중 3회 오프라인 참여)
- **혜택**:
  - 도서 10% 할인
  - 오프라인 공간 무료 이용
  - 추가 워크샵 참여
  - 전용 커뮤니티 활동

#### 정규 멤버
- **비용**: 프로그램별 상이 (예: 89,000원/4주)
- **혜택**:
  - 도서 구매 권장
  - 커뮤니티 네트워킹
  - 심화 깊은 대화

### 모임 참여 TIP

#### 📖 사전 준비
- 첫 모임 전 해당 도서 1~3챱 정도 읽기
- 기본적인 저자 및 배경지식 파악
- 토론에 참여할 주제 미리 생각

#### 💬 적극적 참여
- 질문了两려움 있게 질문하기
- 다른 멤버의 의견 존중히 경청
- 솔직한 경험 공유하기

#### 🤝 네트워킹
- 모임 전후 모임원들과 교류
- 온/오프라인 네트워킹 활용
- 다른 카테고리 모임도 참여해보기

## ✍️ 후기 작성

### 후기 작성 방법

#### 작성 시점
- 모임 종료 후 작성 추천
- 모임 진행 중에도 작성 가능
- 언제든 작성 가능 (단, 신뢙성 유의)

#### 후기 내용 구성
```markdown
1. 모임 만족도 (별점 평가)
   - 클럽장님의 리더십 ★☆☆☆☆
   - 프로그램 구성 ★☆☆☆☆
   - 멤버들의 참여 ★☆☆☆☆

2. 가장 기억에 남는 부분
   - 새로운 인사이트를 얻게 된 부분
   - 책에서 실제 적용하게 된 부분
   - 다른 멤버들과의 대화

3. 개선 제안 (선택사항)
   - 다음 모임에서 개선되었으면 하는 부분
   - 프로그램 구성에 대한 의견

4. 추천 대상 (선택사항)
   - 이 책을 누구에게 추천하고 싶은지
   - 어떤 분야에 관심이 있는 분들
```

#### 후기 작성 TIP
- **진솔한 경험**: 실제로 겪은 느낌 그대로 작성
- **구체적 예시**: "같자를 놓치고 간식하자..." 같이
- **길이 적절**: 너무 길면 읽히지 않을 수 있음
- **존중말회**: 타인을 칭찬하는 내용 작성

### 후기 확인 방법
- 해당 모임 페이지 하단 "후기" 탭
- 작성한 후기가 최대 24시간 내에 반영
- 모든 후기는 클럽 매니저 검토 후 게시

## ❓ 자주 FAQ

### 회원가입 관련

#### Q: 비회원도 도서를 탐색할 수 있나요?
A: 네, 가능합니다! 회원가입 없이 카테고리별 300선 도서를 탐색하실 수 있습니다.

#### Q: 가입 비용이 있나요?
A: 기본 회원가입은 무료입니다. 1st Season 멤버십에 가입하려면 월 3회 오프라인 모임 참여가 필요합니다.

#### Q: 회원 탈퇴는 어떻게 하나요?
A: 마이페이지 > 계정 설정 > 회원 탈퇴에서 가능합니다. 탈퇴 시 모든 데이터는 보존되나, 참여 중인 모임에서는 제외됩니다.

### 모임 참여 관련

#### Q: 책을 구매해야 하나요?
A: 기본적으로 모임 비용에 도서가 포함되어 있습니다. 다만 별도로 책을 소장하고 계신해서 읽고 오시면 더 깊은 대화가 가능합니다.

#### Q: 초보자도 참여 가능한가요?
A: 네, 가능합니다! "입문자용" 또는 "기초" 모임이 별도 운영되고 있으니 자신의 수준에 맞는 모임을 선택하세요.

#### Q: 한 번 선택한 모임을 변경할 수 있나요?
A: 모임 시작 3일 전까지는 환불 가능합니다. 그 이후에는 담당 매니저에게 문의해주세요.

### 결제 관련

#### Q: 환불 불가 시 어떻게 되나요?
A: 모임 시작 7일 전 100% 환불, 3일 전 50% 환불되며 그 이후에는 환불이 불가합니다. 단, 담당 매니저와 협의 시 예외적으로 처리될 수 있습니다.

#### Q: 결제 영수증이 발행되지 않았어요.
A: 먼저 스팸 메일이나 토스/카카오페이 앱에서 확인해주세요. 그래도 안 될 경우 담당 관리자에게 문의해주세요.

#### Q: 1st Season 멤버십 할인은 없나요?
A: 현재 1st Season 멤버십 할인은 없습니다. 정기적으로 프로모션 진행 시 할인 코드를 제공해 드립니다.

### 기술 문제

#### Q: 이미지가 제대로 로딩되지 않아요.
A: 
1. 페이지 새로고침 (Ctrl+F5 또는 Cmd+R)
2. 캐시 삭제 후 재접속
3. 다른 브라우저로 시도

#### Q: 알라딤 도서 링크가 작동하지 않아요.
A: 알라딘 서버 일시 오류일 가능성이 높습니다. 잠시 후 다시 시도해 보시고, 계속 문제시 고객센터 팀에 알려주세요.

#### Q: 모임 검색이 안 돼아요.
A: 
1. 검색어에 스펰이 없는지 확인
2. 카테고리 필터 리셋
3. 페이지 새로고침

### 콘텐츠 및 기타

#### Q: 원하는 카테고리의 도서가 없어요.
A: 300선 도서 큐레이션을 지속 업데이트하고 있습니다. 희망하는 도서가 있다면 클럽 매니저에게 제안해 주세요.

#### Q: 오프라인 모임 장소가 정확히 어디인가요?
A: 서울특별시 종로구 창경궁로 270 (혜화역 4번 출구에서 도보 3분). 상세 주소는 모임 페이지에서 확인하실 수 있습니다.

#### Q: 취소/환불 시 어떻게 되나요?
A: 
- 모임 시작 7일 전: 100% 환불
- 모임 시작 3일 전: 50% 환불
- 그 이후: 불가 (단, 의료시 긴급 사유는 담당 매니저와 협의 필요)
