02. 개발 환경 및 시스템 인프라 개요
프론트엔드 (Frontend)
  • • Core: React 18, TS, Vite
  • • Styling: TailwindCSS (Ace Hotel)
  • • Palette: #F6F5F1 캔버스, #111111 블랙
  • • Frame: 100% 직사각형(rounded-none)
백엔드 & DB
  • • Database: Supabase PostgreSQL
  • • Tables: rooms, reviews, inquiries
  • • Client: Supabase JS v2
  • • Security: Row Level Security (RLS)
배포 & 파이프라인
  • • Hosting: Vercel Production
  • • SPA Rewrites: vercel.json (outDir)
  • • API: api/book-cover.js (알라딘 프록시)
  • • Admin: Streamlit + Gemini API

03. 시스템 환경 변수 (.env) 설정 가이드
환경변수 Key 설명 및 설정 값 예시 비고 / 사용처
VITE_SUPABASE_URL https://fewzfqkqmdfbfqdtxmvf.supabase.co Supabase 프로젝트 접속 URL
VITE_SUPABASE_ANON_KEY eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9... Supabase Public Anon Key
VITE_ALADIN_TTB_KEY ttbjwl17220625001 알라딘 Open API TTB Key
⚠️ Vercel 배포 및 보안 주의사항 (Security Checklist)

1. Vercel Dashboard [Project Settings] -> [Environment Variables]에 위 3가지 변수를 반드시 등록해야 합니다.
2. VITE_ 접두사가 포함된 변수는 클라이언트에 노출되므로, Supabase service_role 비밀키는 절대 Vercel에 노출하지 마십시오.
